# Dify #42889 reality delta — selected source, hidden middle span

Source run:
https://github.com/hippoley/ContextMesh/actions/runs/35966935382

Upstream commit tested:
`989ba1a78ffd1b9cb73a0f5cbce37b8ab39f5890`

## What was reproduced

A synthetic `SKILL.md` was constructed with one decisive import-safety instruction in the middle.

Measured on current Dify main at the tested commit:

| Property | Value |
| --- | ---: |
| source size | 11,343 bytes |
| ordinary shell head budget | 4,096 bytes |
| ordinary shell model-visible budget | 8,192 bytes |
| rendered visible observation | 8,339 bytes including truncation marker |
| decisive middle marker visible | **no** |
| eager-pull complete-output budget | 1,048,576 bytes |

The source itself was available. The failure happened later:

```text
source selected
    ↓
source read
    ↓
shell observation transport
    ↓
first 4 KiB + truncation marker + last 4 KiB
    ↓
decisive middle instruction is absent from model-visible context
```

This is a different blind-spot class from top-k retrieval loss.

## Why this matters to ContextMesh

A source-level coverage metric alone would call this 100% selected coverage and still be wrong.

The useful distinction is:

1. **eligibility coverage** — was the source allowed to participate?
2. **transport/content coverage** — which source spans were actually exposed?
3. **semantic visibility** — did the decisive span survive into model-visible evidence?

ContextMesh v0.15 now has a matching `middle-instruction-truncation` Reality Probe and records `selected-but-semantic-span-hidden` in its eligibility trace.

## Fix boundary

The probe does **not** support simply increasing every shell observation limit.

The safer upstream direction is an instruction/skill-specific full or paginated read contract, because arbitrary shell output needs a bounded model-facing budget.

Candidate designs to validate against Dify main:

- dedicated skill-read tool returning bounded pages with explicit continuation;
- `config skills pull --json` path exposing `skill_md` directly when the model requested a skill;
- explicit structured attachment for instruction sources, separate from generic shell stdout.

## Limits

This is a current-main code-path reproduction, not an end-to-end claim that every Agent V2 execution produces the wrong answer.
