Where did the evidence disappear?

ContextMesh is not trying to rank every source better. It tests a narrower claim: ranking, truncation and routing must not silently decide what evidence is allowed to exist at judgment time.

Every case below was reproduced against a real open-source project or current dependency path. Each card separates the measured result from the interpretation limits.

Evidence lifecycle

Coverage is a path, not a single percentage.

ContextMesh now records where a source stopped being usable, including byte-range visibility when a transport truncates content.

1Ingestedsource entered runtime
2Storedaddressable payload exists

4Eligibleallowed downstream

6Model-visibledecisive semantics survive

A source can be “retrieved” and still be lost at eligibility. It can be “selected” and still be lost at rendering. The diagnostic should name the first stage where evidence stopped being trustworthy.
