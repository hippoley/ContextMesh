This public deployment is the static product surface. It runs in demo mode today. Point the frontend at a real ContextMesh FastAPI deployment to activate ingest jobs, SSE progress, provider routing, full-coverage evaluation and LMCache telemetry.

Evaluation API

POST /api/evaluation-jobs

{
  "corpus_id": "corp_xxx",
  "question": "...",
  "answer": "...",
  "route_id": "local-qwen"
}

The server reads every required ContextBlock, checkpointing progress and refusing a final score until ingest, semantic and execution coverage gates pass.

Provider adapters own modality payloads and context limits. Corpus storage remains provider-neutral; KV cache is a model-specific acceleration artifact.

Large-file path

Browser
  → resumable upload
  → S3 / MinIO
  → ingest worker
  → ContextBlock catalog
  → full-coverage reader

The repository build currently includes the local-store reference path. Production should swap the object-store and durable queue adapters without changing ContextBlock or evaluator semantics.
